# AI Coding 演变史

## 四个阶段
AI Coding 的发展大致可以分为四个阶段，每个阶段都对应着开发范式的重大转变。

### 阶段一：代码补全时代（2021-2022）
**代表产品**：GitHub Copilot（首个主流产品，2021 年 10 月正式发布）

**核心能力**：
- 基于上下文的**单行/多行代码补全**-类似 IDE 原生补全，但能跨文件理解
- "打字就有提示"的体验

**局限**：
- 只能补全，无法对话
- 上下文窗口小（最初约 4K tokens）
- 无法理解整个项目

**对开发者的影响**：从"手写每一行代码"变为"接受/拒绝补全建议"，效率提升 10-30%（经验估算）。

### 阶段二：聊天式 AI 辅助（2023）
**代表产品**：ChatGPT、Copilot Chat、文心一言、通义千问

**核心能力**：
- **对话式交互**：可以提问、解释代码、生成代码片段
- 自然语言描述需求 → AI 输出代码
- 支持解释、翻译、重构等多种任务

**关键事件**：
- 2023 年 3 月 GPT-4 发布，代码能力大幅跃升
- 2023 年中 Cursor 1.0 发布，AI 原生编辑器概念兴起
- Claude 2 / Claude 3 在长上下文与代码质量上领先

**局限**：
- 聊天窗口与编辑器割裂，需要手动复制粘贴
- 上下文难以持久化

### 阶段三：AI 原生编辑器与 Agent（2024）
**代表产品**：Cursor（成熟）、Trae（AI 原生 IDE）、Windsurf

**核心能力**：
- **编辑器内深度集成**：选中代码、AI 侧栏、Inline Edit
- **Agent 模式**：AI 可以自主规划、执行多步任务
- **代码库索引**：理解整个项目结构和语义
- **多文件编辑**：一次任务可跨多个文件

**关键事件**：
- 2024 年初 Cursor Composer 模式发布，多文件编辑成为标配
- 2024 年 Claude 3.5 Sonnet 在 SWE-bench 上大幅领先（编码能力第一波飞跃）
- 2024 年底 Cursor、Trae 等 AI 原生 IDE 兴起

**对开发者的影响**：从"逐行写代码"转向"描述意图、AI 执行、审查结果"。

### 阶段四：终端 Agent 与 CLI 范式（2024 末 - 2025）
**代表产品**：Claude Code、CodeX CLI、OpenCode、Aider

**核心能力**：
- **命令行 Agent**：直接在终端工作，适合脚本化、自动化场景
- **更强的自主性**：可执行命令、修改文件、运行测试
- **适合复杂重构**：跨项目、跨模块的大规模改动
- **与 Git 深度集成**：自动创建分支、提交、PR

**关键事件**：
- 2024 年底 Anthropic 发布 Claude Code
- 2025 年 OpenAI 发布 CodeX CLI
- 终端 Agent 范式成为继 IDE 集成之后的第二条主线

### 阶段五：多模型协同与 1M 上下文（2025 末 - 2026）
**代表产品**：Claude Code（Agent Teams + Opus 5 1M 上下文）、Cursor Composer 2.5、自定义模型网关

**核心能力**：
- **多模型角色分工**：架构师（Opus 4.6）+ 主力（Sonnet 4.6）+ 评审（Gemini 3.5 Flash）+ 文档（DeepSeek V3.2）协同
- **超长上下文**：Claude Opus 5 / Gemini 3.1 Pro 已支持 1-2M tokens
- **Agent Teams**：并发子代理处理超大型任务
- **国产模型崛起**：GLM-5（77.8% SWE-bench）、Kimi K2.5、DeepSeek V3.2 已具备主力化条件
- **跨厂商备份**：避免单一厂商账号风控（2026 已发生多次封号事件）

**关键事件**：
- 2026-02-05 Claude Opus 4.6 发布（$5/$25，首次将 1M 上下文带入 Opus 系列）
- 2026-02-17 Claude Sonnet 4.6 发布（$3/$15，70% 场景达到上代 Opus 水平）
- 2026-03-14 Claude Opus 4.6 / Sonnet 4.6 1M 上下文转标准定价（取消长上下文溢价）
- 2026-04 OpenAI 推出 GPT-5.5（$5/$30，1M 上下文，编码能力 SOTA）
- 2026-07 Anthropic 推出 Claude Sonnet 5（$2/$10，限时首发价）、Fable 5、Opus 4.7/4.8
- 2026-08 Claude Opus 5 登顶 SWE-bench Verified（96% 解决率，1M+ 上下文）
- 2026 多模型结构化传递范式成熟（用 JSON Schema 在模型间传递，不传原始对话历史）

**对开发者的影响**：从"用 AI"升级到"管 AI 团队"——选模型、定路由、监控成本、备份链路成为核心技能。

::: tip 为什么"终端 Agent"重要？
很多场景下，开发者并不在写新功能，而是在：
- 重构老代码
- 排查 Bug
- 批量修改（升级依赖、批量改 API）
- 跑测试、查日志

这些场景**终端 Agent 比 IDE 更高效**。这也是为什么 Cursor（IDE）+ Claude Code（CLI）的组合成为很多团队标配。
:::

## 趋势观察
未来 12-24 个月的关键趋势：

1. **Agent 自主性增强**：从"需要审查每一步"到"只需审查最终结果"
2. **多 Agent 协作**：规划 Agent + 编码 Agent + 测试 Agent 协同
3. **更长上下文**：百万级 token 上下文让"喂整个仓库"成为可能
4. **垂直化**：前端、后端、数据等垂直场景的专用工具
5. **本地化部署**：对代码安全敏感的团队可在本地运行模型
