# 成本治理（2026 版）
> 数据基准：2026 年 8 月。**Sonnet 4.6 与 Opus 4.6 编码能力仅差约 1 个百分点**（SWE-bench 79.6% vs 80.8%），但价格相差 5 倍。这一变化让"默认 Opus"成了最大的成本反模式。**GPT-5.5 首发定价 $5/$30**（2026-04）也让 GPT 不再是"全能性价比"选项。

## 成本的全景图
AI Coding 的成本**不只是订阅费**，还有 4 大类：

```
总成本
├── 工具订阅（Cursor、Claude Code 等）
├── API 调用（按 Token 计费）
├── 时间成本（等待 AI 响应）
└── 隐藏成本（返工、误用、安全事件、厂商锁定）
```

> **2026 新增风险**：单一厂商账号封禁可能让所有 skills、配置、对话记录瞬间蒸发（Anthropic 曾一次性封禁 60+ 账号），属于**新型隐藏成本**。

## 3. 成本优化策略（2026）

### 策略 1：模型分层（最重要的优化）
> **核心原则**：80% 任务用 Sonnet 4.6，仅关键任务切 Opus 4.6/5。

```markdown

## 2026 推荐模型分层

### 简单任务（用便宜模型）
- 代码补全：Cursor Composer 2.5（自研，免费/订阅内）
- 中文文档：DeepSeek V3.2（$0.28/$0.42）
- 批量生成：DeepSeek V3.2 / Gemini 3.5 Flash
- 简单问答：DeepSeek V3.2 / Haiku 4.5

### 中等任务（用中等模型）—— **主力**-日常编码：Claude Sonnet 4.6（$3/$15）← **默认**-组件生成：Sonnet 4.6 / GPT-5.4
- Bug 修复：Sonnet 4.6
- 常规重构：Sonnet 4.6

### 复杂任务（用顶级模型）—— **仅必要时**-大型重构：Claude Opus 4.6 / 5（$5/$25）
- 架构设计：Claude Opus 4.6
- 关键 Bug：Claude Opus 4.6
- 大型代码库分析：Claude Opus 5（1M 上下文）

### 多模态任务
- 看图写前端：Kimi K2.5（262K 原生视觉）
- 长 PDF / 视频：Gemini 3.1 Pro（1M 上下文）
```

**收益**：相比"全 Opus"，分层使用可节省 **60-70% 成本**，代码质量损失可忽略（Sonnet 4.6 与 Opus 4.6 在 SWE-bench Verified 上仅差约 1 个百分点，但价格相差 5 倍）。

### 策略 2：上下文优化
```markdown

## 减少 Token 消耗

### 1. 精准引用
 @Codebase（整个代码库，100K+ tokens）
 @file + @folder（精准文件，10K tokens）

### 2. 摘要替代
 给完整代码（5K tokens）
 给代码摘要（500 tokens）

### 3. 避免重复
 每个对话重复 agents.md
 一次性配置，加载一次（Claude Code CLAUDE.md / Cursor .cursorrules）

### 4. 及时清理
 长对话保留所有历史（成本爆炸）
 任务结束开新对话（/clear）
 大任务拆分成多个会话

### 5. 利用缓存
 Prompt caching（Claude Sonnet 缓存输入 $0.30/1M，比原价便宜 10x）
 重复使用的内容（agents.md、CLAUDE.md、常见代码）走缓存
 Cursor / Claude Code 已原生支持
```

```typescript
// 记录每次 AI 调用
interface AIUsage {
  timestamp: Date
  userId: string
  model: string              // 记录用了哪个模型
  provider: string           // 2026 新增：记录厂商
  inputTokens: number
  outputTokens: number
  cachedTokens?: number      // 2026 新增：缓存命中
  cost: number
  task: string
}

async function trackUsage(usage: AIUsage) {
  await db.insert('ai_usage', usage)

  // 实时告警
  if (usage.cost > 5) {
    alert('High cost task', usage)
  }

  // 2026 新增：模型分层告警
  if (usage.model.includes('opus') && usage.task === 'code-completion') {
    alert('错误使用：用 Opus 做代码补全，请切 Sonnet', usage)
  }
}
```

### 成本仪表盘
```typescript
// 按模型 / 厂商聚合（2026 关键）
const costByProvider = await db.query(`
  SELECT
    provider,
    model,
    SUM(cost) as total_cost,
    SUM(input_tokens) as total_input,
    SUM(output_tokens) as total_output,
    SUM(cached_tokens) as total_cached,
    COUNT(*) as calls
  FROM ai_usage
  WHERE timestamp > NOW() - INTERVAL '30 days'
  GROUP BY provider, model
  ORDER BY total_cost DESC
`)
```

## 6. 隐藏成本

### 返工成本
```
AI 生成的代码
   ↓
测试发现 Bug
   ↓
人工修复
   ↓
返工成本 = 修复时间 × 人力成本
```

**2026 数据**：用 Sonnet 4.6 生成代码的返工率约 15-25%（比 2025 年的 30-50% 大幅降低）。

### 上下文切换成本
```
使用 AI 时
   ↓
等待响应（5-30 秒）
   ↓
切换任务（失去专注）
   ↓
切换回来（重新进入状态）
```

**估算**：每天损失 30-60 分钟。

### 误用成本
```
用 AI 做不适合的任务
   ↓
AI 输出"看起来对"
   ↓
生产事故
   ↓
修复成本 = 紧急修复时间 × 紧急加成
```

### 安全事件成本
```
敏感信息发给 AI
   ↓
数据泄露
   ↓
法律、客户、声誉损失
   ↓
可能是数十万到数百万
```

### 单厂商锁定成本（2026 新增）
```
把所有 skills、配置、上下文押注单一厂商
   ↓
账号被封（Anthropic 2026 年已发生）
   ↓
所有配置 / 对话 / 历史蒸发
   ↓
恢复时间：数日到数周
   ↓
机会成本：数万元到数十万元
```
