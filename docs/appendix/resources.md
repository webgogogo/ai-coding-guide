## 书籍推荐

## 自学建议

### 入门到进阶路径
```
阶段 1：建立认知（1-2 周）
  - 读本指南的 quickstart
  - 试用 Trae / Cursor
  - 关注 1-2 个 Newsletter

阶段 2：建立能力（1-2 月）
  - 精读本指南
  - 写自己的 agents.md
  - 尝试 3 种编码模式
  - 看 YouTube 实战视频

阶段 3：建立体系（3-6 月）
  - 团队推广
  - 度量自己的效率
  - 关注前沿论文 / 报告
  - 加入社区讨论
```

### 信息源选择原则
1. **不要追所有新东西**：选 2-3 个高质量信息源深读
2. **官方优先**：模型/工具的官方文档、博客、Release Notes
3. **二手谨慎**：博主解读可能有偏差，关键决策要回官方
4. **避免 FOMO**：别人的工作流不一定适合你

### 学习方式建议
| 方式 | 适合 |
| --- | --- |
| 系统阅读（书籍） | 建立完整知识体系 |
| 短文 / 教程（博客） | 学习具体技能 |
| 视频（B 站、YouTube） | 看实战、跟做项目 |
| 播客 | 通勤时了解行业 |
| 动手做 | 任何新工具都要试 30 分钟 |
| 教别人 | 真正掌握知识的最好方式 |
