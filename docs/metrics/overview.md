## 为什么需要度量
没有度量，就不知道：

- AI Coding 到底有没有用？
- 哪个工具/模式效果最好？
- 团队的瓶颈在哪里？
- 投入产出比如何？

## 度量的核心原则

### 1. 度量目标，而非活动
```markdown
 度量"AI 调用次数"（活动指标）
 度量"任务完成时间"（目标指标）

 度量"Prompt 模板数量"（活动指标）
 度量"代码一次通过率"（质量指标）
```

### 2. 综合度量，不只看速度
```markdown
不只看：开发速度快不快
还要看：
- 代码质量高不高
- Bug 多不多
- 团队满意不满意
- 成本可控不可控
```

### 3. 持续度量，定期回顾
```markdown
- 每周：收集数据
- 每月：分析趋势
- 每季度：调整策略
```
