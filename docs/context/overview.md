# 上下文工程：决定 AI Coding 质量的关键

> **Prompt 决定 AI 的下限，上下文决定 AI 的上限。**没有好的上下文，再好的模型也写不出符合你项目要求的代码。

## 什么是上下文工程

为 AI 准备**最优输入信息**的实践，涵盖 Prompt 写法、项目结构、规范文档、模板库、上下文用量、多 Agent 协同等。

```
            └─────────────────────────────────────────┘
```

## 为什么它重要

```
没有上下文：             有上下文：
「帮我写个用户列表」     「参考 @agents.md 写用户列表，
 ↓                       用 React Hooks + TS 严格模式，
 AI 输出 class 组件、    走 services/ 拿数据，
 用 MobX、内联样式       覆盖 loading/empty/error 三态」
 ↓                       ↓
 返工率 80%              一次可用率 80%
```

> 经验估算：1 天写好 agents.md，AI 生成代码可用率 +30%；1 天整理模板，团队整体效率 +50%。

## 实战原则

**DO**

- 项目结构清晰、命名一致
- 写好 agents.md，团队共享
- 掌握 Prompt 工程六要素，每次写清楚意图
- 高频任务做成模板
- 每次任务明确指定上下文范围

**DON'T**

- 让 AI 猜项目约定
- 每次重复说明同样的话
- 用过大的上下文（污染）
- Prompt 过于模糊或冗长
- 把 agents.md 写成"百科全书"
